                  Help

                  How to use the app

                  1) Add Sites

                  Go to Plant & Sites → Sites. Create each project/site once.

                  2) Add Equipment

                  Plant & Sites → pick a category tab (Yellow, Small, Trucks, Bakkies) and add items. For Small Plant, choose a subtype.

                  3) Create Hires

                  Hire → New Hire. Select site, plant and start date. Return later when done. Allocation updates automatically.

                  4) Month‑end Readings

                  Maintenance → choose Yellow/Trucks/Bakkies. Enter the month‑end hours (Yellow) or km (Trucks/Bakkies). You can view previous month values and save for the selected month.

                  5) Service Reminders & Licenses

                  Maintenance → open a category list and click “Service settings” for an item. Yellow: up to 5 reminders with interval and next due. Trucks/Bakkies: one reminder. Add license renewal dates. Warnings show here and a red badge on the Maintenance tab.

                  6) Reports

                  Reports → Site • Month or Whole Contract. Weekends excluded for day rates. Enter Hours for per‑hour and KMs for per‑km lines before Print/PDF. You can save monthly results to the site’s lifetime totals.

                  7) Invoice Inbox (manual pre-conversion)

                  Invoices → New Invoice lets you attach a PDF/image and capture supplier, invoice number/date, plant, maintenance type and amount fields. In the Windows desktop app, attachments are copied into the app’s documents folder so they survive restarts and backups. Use Read invoice with OCR to draft suggestions, review them carefully, apply only the values you want, then save normally. OCR and any future AI review never post or save an invoice automatically.

                  Printing

                  Click Print/PDF on the report. The browser print dialog will open. If quantities are missing (hours/kms), you’ll be prompted to fill them in.

                  Data storage

                  Browser mode still saves data in your browser on this device. In the Windows desktop app, SQLite is the live day-to-day data store and invoice attachments are kept as real files in the app’s documents folder. Use Help → Desktop / Database to create a combined desktop backup or restore one. Keep at least one backup copy outside this PC as well, for example on a USB drive or OneDrive.

                  Export / Import

                  Export saves a .json file containing all Sites, Plant, Hires, Maintenance, Invoices, invoice document references, Month‑end readings, Service settings and Lifetime totals. In desktop mode, the real invoice files are protected by the Desktop / Database backup feature instead. Import loads a previously exported file. Importing will replace current data on this device.

                  Invoice OCR & Local AI (optional)

                  Local invoice reading works only in the Windows desktop app. OCR suggestions and Local AI suggestions are always review-only. Nothing is auto-saved, auto-posted, or auto-applied.

                  Status:
                  Checking Local AI status…

                  Local AI uses OCR text only. This feature does not send original invoice files/attachments to the model.

                  Windows setup (manual, recommended):

                  1) Install Ollama for Windows and start it.
2) In PowerShell:
   [Environment]::SetEnvironmentVariable("OLLAMA_MODELS","C:\OllamaModels","User")
3) Restart Ollama.
4) Pull the model:
   ollama pull qwen2.5:1.5b-instruct-q4_K_M
5) Return here, click Check Local AI status, then enable Local AI.

                  On older CPU-only PCs this step can be slow. Run one invoice at a time and wait for each review to finish.
